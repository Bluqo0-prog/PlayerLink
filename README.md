
# PlayerLink

Find players. Discover connections.

PlayerLink is a Minecraft Java and Discord integration platform.

## Features

- Minecraft player lookup
- Minecraft UUID and skin retrieval
- Verified Discord account linking
- Authorized mutual Discord server discovery
- Minecraft Fabric mod integration
- Searchable web interface

## Project Structure

- web/ — PlayerLink website
- backend/ — Shared API and Discord integration
- mod/ — Minecraft Fabric mod

## Status

Early development.
